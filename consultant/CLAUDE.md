\# VTMF settings work

This folder is for managing VTMF settings in customer databases. There is no code here.

\- Words like "feature", "setting", "column", "layout", "process", "client", "table" always mean

&#x20; VTMF settings. Use the vtmf-settings MCP tools and skills, never file search.

\- Feature work: create-feature (new or fix a feature), apply-feature (apply to a customer).

&#x20; Settings changes: manage-settings.

\- Start every task with list\_clients / module\_status if the client is unknown.

\- Never read or grep files to answer settings questions.
